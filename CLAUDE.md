# CLAUDE.md

Тренажёр к экзамену ОФСЛА для пилотов парапланов. Сейчас есть только банк вопросов, извлечённый из PDF. Формат приложения (веб или Telegram-бот) ещё не выбран. Контент и интерфейс — на русском.

## Команды

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python tools/extract_questions.py   # перегенерирует data/questions.json и data/img/
```

## Данные

- `data/questions.json` и `data/img/` **генерируются** — руками их не править. Исправления текста вносятся в `TEXT_FIXES` в `tools/extract_questions.py`, после чего данные перегенерируются.
- Формат JSON описан в README.md. Будущие приложения опираются на него, поэтому поля (`type`, форма `correct`, `image`) менять только вместе с потребителями.
- Текст сохраняется как в источнике, включая опечатки. Исправляются только гомоглифы (кириллица вместо латиницы).

## Особенности PDF (doc/pilot_svs_115_bez_otvetov.pdf)

- Несмотря на «bez_otvetov» в имени, ключ есть: страницы «Ключи» в конце документа. Для сопоставлений в ключе записаны блоки строк `a - b`, а номер вопроса стоит по вертикальному центру блока.
- Разбор идёт по координатам (PyMuPDF), а не по потоку текста. Колонки и кегли заданы константами в начале скрипта. Текст вопроса набран кеглем 10–12, варианты — 8, заголовки разделов — 13 (могут занимать две строки).
- Текст варианта центрирован по вертикали относительно его номера, поэтому строка относится к ближайшему номеру.
- Картинки 32×32 — это иконки радиокнопок, их пропускаем. Картинку вопроса рендерим как область страницы: так сохраняются составные рисунки и подписи «1 2 3».
- Вопросы и варианты переходят со страницы на страницу, а заголовок `№N (1)` может стоять последней строкой страницы.
